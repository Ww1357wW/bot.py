# Bot.py Project

یک سیستم ربات ساده و مدرن در Python

## 📋 فایل‌های پروژه

- `bot.py` - کد اصلی ربات
- `requirements.txt` - وابستگی‌های پروژه
- `pytest.ini` - تنظیمات pytest
- `setup.sh` - اسکریپت راه‌اندازی خودکار

## 🚀 نحوه استفاده

### گزینه 1: استفاده از اسکریپت setup.sh

```bash
bash setup.sh
```

این اسکریپت به صورت خودکار:
- Dependencies را نصب می‌کند
- کد را فرمت می‌کند (black)
- کد را بررسی می‌کند (flake8 & pylint)
- تست‌ها را اجرا می‌کند

### گزینه 2: دستورات دستی

```bash
# نصب وابستگی‌ها
pip install -r requirements.txt

# فرمت کردن کد
black .

# بررسی کد
flake8 .
pylint bot.py

# اجرای تست‌ها
pytest

# اجرای ربات
python bot.py
```

## ✅ تست‌ها

پروژه دارای تست‌های جامع است:
- تست ایجاد ربات
- تست شروع و متوقف کردن
- تست پردازش پیام

## 🔧 ویژگی‌های Bot

- `__init__(name)` - ایجاد نمونه جدید
- `start()` - شروع ربات
- `stop()` - توقف ربات
- `process_message(message)` - پردازش پیام

اگر مشکلی داشتید، می‌توانید فایل‌ها را ویرایش کنید.
